# 동현주 v0.03

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24048918.svg)](https://doi.org/10.5281/zenodo.24048918)

같은 얼굴 **셋을 나란히** 맞추면 잡히는 얼굴 판 퍼즐이다. 이웃한 두 얼굴을 바꿔 가로나 세로로 같은 얼굴 셋 이상을 놓으면 잡히고, 얼굴마다 정해진 수를 잡으면 다음 단계다. **시작 단계**와 **쌍안경** 횟수를 동현랭으로 정한다.
동현 시리즈의 열한 번째 작은 실험이다.

바로 하기: https://raspberry-kim.github.io/donghyun-lab11/

## 놀이 방법

- 처음 열면 판 위에 **시작** 단추가 떠 있고 시간은 멎어 있다. 시작(키보드 X·Enter, 패드 A)을 누르면 판이 돈다. 동현랭 코드의 시작을 누르면 그 설정으로 바로 새 판이 돈다.
- 가로나 세로로 이웃한 두 얼굴만 바꿀 수 있다. 바꿔서 같은 얼굴이 셋 이상 나란히 놓이면 잡히고, 아니면 제자리로 되돌아온다.
- 잡힌 자리로 위의 얼굴이 떨어지고 새 얼굴이 내려온다. 떨어지며 또 맞으면 **연쇄**다. 연쇄 중에도 멎어 있는 얼굴은 바로 바꿀 수 있다.
- 판 오른쪽(휴대폰은 위)의 숫자는 얼굴마다 더 잡아야 하는 수다. 일곱 얼굴이 모두 0이 되면 다음 단계, 20단계를 마치면 끝이다.
- 왼쪽(휴대폰은 위) 막대가 시간이다. 잡을수록 다시 차고, 비면 끝이다. 바꿀 자리가 하나도 없으면 판을 새로 섞는다(시간은 간다).
- **쌍안경**: 바꿀 수 있는 자리를 모두 2초 동안 파랗게 보여 준다. 5,000점마다 하나 는다(최대 9).
- 3단계부터 가끔 **보병**이 내려온다. 어느 얼굴과도 줄을 이루고 목표에는 들지 않으며, 보병이 든 묶음은 점수 2배다. 2단계부터는 얼굴이 계속 바뀌는 **반짝 판**이 드물게 내려오고, 누르면 그 순간 보이는 얼굴을 판에서 모두 잡는다.

## 단계·시간·점수

| 항목 | 값 |
|---|---|
| 판 | 8×8, 얼굴 일곱 가지 |
| 목표 | 1~3단계 3마리, 4단계부터 하나씩 늘어 12단계부터 12마리 |
| 시간 막대 | 1단계 32초, 단계마다 1.1초씩 짧아져 20단계 12초 |
| 다시 차는 양 | 셋 8% · 넷 14% · 다섯 이상 22% (보병 묶음 +20%) |
| 한 묶음 | 셋 30 · 넷 60 · 다섯 90 (여섯 이상은 하나당 30씩 더) × 연쇄(최대 ×8) × 단계(+10%씩) |
| 반짝 판 | 잡힌 얼굴 하나당 20점(단계 배수 적용) |
| 단계 마침 | 500 × 단계 + 남은 시간(최대 1,000) |

오늘·이번 주(월요일 시작)·역대 최고 점수는 브라우저의 localStorage에만 저장한다.

## 동현주 규약

동현랭 코드가 출력한 **정수 둘**이 차례로 시작 단계와 쌍안경 횟수다.

| 출력 | 뜻 |
|---|---|
| `1` `3` | 기본값(1단계, 쌍안경 3) |
| 1–20, 0–9 | 쓸 수 있는 범위. 쌍안경이 0이면 단추를 쓸 수 없다 |
| 출력 없음 | 기본값 1, 3으로 시작 |
| 정수 하나, 셋 이상, 범위 밖 | 시작하지 않고 오류를 알린다 |

예제는 `01 · 기본 (1 · 3)`, `02 · 중간부터 (8 · 5)`, `03 · 맨눈 (1 · 0)`, `04 · 마지막 단계 (20 · 9)` 넷이다.

```
나는 동현이냐?
ㅋㅋ 기본 · 1단계 · 쌍안경 3
ㅋㅋ 시작 단계 1
뿡뿡 도옹~뿡뿡뿡
ㅋㅋ 쌍안경 3
뿡뿡 도오오옹~뿡뿡뿡
동현이구나
```

코드는 판의 얼굴이나 바꿀 자리를 고르지 않는다. 판은 처음부터 맞춰진 줄이 없고 바꿀 자리가 적어도 하나 있게 뽑는다.

## 조작

- **마우스·터치**: 얼굴을 누른 뒤 이웃 얼굴을 누르면 바뀐다. 누른 채 이웃 쪽으로 끌어도(쓸어도) 된다. 같은 얼굴을 다시 누르면 고름이 풀린다.
- **키보드**: 화살표로 칸을 고르고 X(또는 Enter·Space)로 집은 뒤 화살표를 누르면 그쪽 얼굴과 바뀐다. Z 취소, S 쌍안경, M 소리.
- **게임패드**: 십자나 왼 스틱으로 고르고 A로 집은 뒤 방향으로 바꾼다. B 취소, X 쌍안경. 닌텐도 배치 기준이며 A·B가 거꾸로면 − 를 한 번 누른다.
- 전체 화면은 없다. 휴대폰은 두 번 두드려도 확대되지 않고 판에서 손가락을 끌어도 화면이 밀리지 않는다(동현텐의 휴대폰 경험). 다른 탭을 보거나 창을 벗어나면 시간이 멎는다.

## 얼굴 출처

포동이 · 슈슈 · 라이언 · 초파리 · 둠가이 · 기사 · 꼬리콥터 일곱 얼굴과 보병은 모두 동현랭 세계관의 인물이다. 포동이는 동현랭의 강아지, 슈슈와 라이언은 동현파, 초파리는 동현초, 둠가이는 동현둠, 기사는 동현워, 꼬리콥터는 동현콥, 보병은 동현전에서 왔다. 동현몬과 같은 글자 팔레트와 윤곽색으로 `tools/paint.py`가 얼굴만 16×16으로 다시 그렸다(원작처럼 얼굴만 보인다).

## 효과음

소리 파일 없이 브라우저 안에서 합성한다(Web Audio). 얼굴을 고르면 톡, 바꾸면 휙, 잡히면 퐁(연쇄는 음이 올라감), 틀리면 낮은 부저, 보병 묶음과 쌍안경은 반짝이는 소리, 반짝 판은 따로 울리고, 판을 섞으면 휘익, 단계를 마치면 딩동댕, 시간이 얼마 남지 않으면 짧은 경보, 끝나면 내려가는 음(20단계를 마치면 올라가는 음)이 난다. 머리말의 스피커 단추나 M 키로 켜고 끈다.

## 원작에 관하여

Robot Communications의 브라우저 게임(2002~2003)으로 시작해 GBA판 「Zooo」(2003, Success)와 DS판 「Zoo Keeper」(2004~2005)로 나온 동물 얼굴 셋 맞추기 퍼즐의 보통 모드(Normal)를 따른다. 다른 모드는 만들지 않았다. 동현주는 원작의 코드·그림·소리·글을 쓰지 않았고, 제작사와 관계가 없다. 구체적인 수치는 동현주가 정한 것이다. 자세한 내용은 [CREDITS.md](CREDITS.md).
